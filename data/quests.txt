# Questline reward items ("quest lots") for Dark Souls III.
# Format: Item | event flag id | NPC
#
# The flag says whether that reward has been handed over, which makes these a
# reliable stand-in for how far a questline has actually progressed - getting
# Siegward's Storm Ruler means you reached the Yhorm stage with him alive.
#
# Sources: the Souls Modding Wiki DS3 event flag list, cross-checked against
# SoulSplitter's item-pickup list. All 80 flag ids below appear in both.
#
# The cross-check corrected four entries where this file had been wrong:
#   50006110  "Princess Ring"  -> "Priestess Ring" (no such item as the former)
#   50006091  "Silver Mask"    -> "Lift Chamber Key" (Silver Mask was listed twice)
#   50006072  "...Torso Stone" -> "...Head Stone" (Torso Stone was listed twice)
#   50006193  Dark Sigil moved from Anri to Yoel, who actually gives it
#
# Known remaining disagreement, left as-is because both readings are defensible:
# where a reward is a full armour set, this file names the set ("Catarina Set")
# and SoulSplitter names the first piece ("Catarina Helm"). Same flag either way.
#
# STILL UNVERIFIED IN GAME. Two independent sources agreeing rules out
# transcription slips, but not a shared upstream mistake. Confirm with
# "main.exe --watch" before trusting the missable warnings built on these.
#
